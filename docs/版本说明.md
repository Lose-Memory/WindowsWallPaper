# 版本说明

> **这份文件只回答一个问题：哪个版本、什么时候出的、改了什么。**
> 一行一条，不展开细节——每一轮的完整交接记录在
> [`AGENTS.md`](../AGENTS.md) 的「最近几轮做了什么」里，功能说明看
> [`README.md`](../README.md)，架构决策看 [`设计规格.md`](设计规格.md)。

## 版本号写在哪（改名时要一起改）

界面上（诊断页与左下角）显示的那个版本号来自 `tauri.conf.json`。
**四个地方必须同时改**，否则会出现"界面显示的版本与实际代码对不上"：

| 文件 | 字段 |
|---|---|
| `package.json` | `version` |
| `src-tauri/Cargo.toml` | `[package] version`，以及依赖 `windows-wallpaper` 那一行 |
| `src-tauri/crates/wwp-core/Cargo.toml` | `[package] version` |
| `src-tauri/tauri.conf.json` | `version` |

`src-tauri/Cargo.lock` 里的版本号由下一次构建自动更新，不用手改。

## 加一条的规矩

出了新版本就在下面那张表里**加一行**（版本 / 日期 / 一句话）。
日期写提交那一天；"改了什么"只写用户能感觉到的变化，一行放得下。
**版本号没变的修订不加行**（例如只改注释、只改文档）——这张表是版本史，
不是提交史。
