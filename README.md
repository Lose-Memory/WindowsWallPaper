# WindowsWallPaper

一个 Windows 桌面壁纸播放器：**每块显示器各自播放自己的图片列表**，互不干扰。

- **每屏独立**：播放列表、间隔、填充方式、筛选条件都按屏设置，谁也不等谁。
- **只有随机**：记住最近 10 张，避免短期重复；播放页同时预览「当前」与「下一张」。
- **大图库也快**：JSONL 索引 + 仅读图片头部，几万张图增量扫描。
- **软件回收站**：不想要的图移进 `data\trash\`，随时恢复原位。
- **NSFW 模式**：一键把每块屏切成固定图并暂停轮播，退出后回到原来那张。
- **便携、常驻托盘**：数据放在程序目录旁，整个文件夹拷走就能用；单实例运行。
- **不还原壁纸、不改你的文件**：退出后桌面留着最后一张。

> 只有图片，没有视频。视频壁纸的实验代码仍留在引擎里，但没有任何调用，运行时不产生开销。

## 快速开始

1. 解压/拷贝 `release\WindowsWallPaper\`，双击 `WindowsWallPaper.exe`。
   不需要安装、不需要管理员权限；程序在同目录建出 `config/`、`data/`、`logs/`。
2. 默认**不弹主界面**，只在托盘待着。点托盘图标打开界面（或按 `Ctrl+Alt+W`）。
3. 「图库」页 →「新增图库」，选一个放图片的文件夹 →「扫描」。
4. 「列表」页 →「新建列表」，勾选要用的图库，设好间隔与填充方式。
5. 回「播放」页，给每块屏选播放列表，点「开始轮播」。

更细的操作（目录树勾选、每屏筛选、固定单图、拖动手柄排序等）见
[TECHNICAL.md](TECHNICAL.md#6-功能细节)。

## 日常使用

- **托盘菜单**：显示主界面 / 切换到下一张 / 轮播中 / NSFW / 退出。后两项带勾显示当前状态。
- **全局快捷键**（「设置」页可改）：

  | 快捷键 | 默认写法 | 作用 |
  | --- | --- | --- |
  | NSFW 模式 | `Ctrl+Alt+S` | 进入 / 退出 NSFW 模式 |
  | 暂停 / 继续 | `Ctrl+Alt+P` | 暂停或继续所有屏 |
  | 下一张 | `Ctrl+Alt+Right` | 所有屏各换一张 |
  | 上一张 | `Ctrl+Alt+Left` | 所有屏各退回上一张 |
  | 显示主界面 | `Ctrl+Alt+W` | 把设置窗口叫出来 |

- **删掉不想要的壁纸**：播放页每屏卡片右上角「删除当前壁纸」→ 移进软件回收站并换下一张。
  到「回收站」页可以**恢复**（放回原位，不覆盖同名文件）或**删除**（送进系统回收站）。
- **NSFW 模式**：在「播放」页给每屏选一张 NSFW 壁纸，点顶部 NSFW 按钮或按快捷键即可。
  再次触发会回到进入之前那张，并继续轮播。
- **改了设置**：保存即生效。想强制按当前设置重建，点播放页「重新加载」——它不会立刻换纸。

## 环境要求

- Windows 10 或更高（逐屏壁纸依赖 `IDesktopWallpaper`，不支持 Windows 7）。
- WebView2 运行时：Windows 11 自带；Windows 10 若没有，装微软官方 Evergreen 版。

## 从源码构建

需要 [Bun](https://bun.sh/)、Rust（stable）、PowerShell 7 与 WebView2。

```powershell
bun install
bun run app:dev                      # 开发模式（前端热重载）
bun run typecheck                    # 前端类型检查
pwsh -File scripts/build-package.ps1 # 构建交付文件夹到 release\WindowsWallPaper\
```

测试：`cd src-tauri; cargo test --workspace`（325 项）。
构建细节、配置字段、数据目录、命令行入口与排查方法都在
[TECHNICAL.md](TECHNICAL.md)。
